# 📊 Data Analysis Projects – Laptop & Furniture Sales

Welcome to my data analysis repository showcasing two hands-on projects using real-world datasets. These projects combine exploratory data analysis (EDA), feature engineering, and light machine learning to uncover insights and predict trends.

---

## 💻 Project 1: Laptop Price Analysis

**Objective:**  
Analyze and predict laptop prices based on specifications like brand, processor, RAM, storage, screen type, and more.

### 🔧 Tools & Tech
- Python, Pandas, NumPy, Matplotlib, Seaborn
- Jupyter Notebook, VS Code
- Data Preprocessing, One-Hot Encoding
- Linear Regression Model

### 📊 Key Steps
- Cleaned and processed 23-column dataset
- Handled categorical features with encoding
- Visualized trends (e.g., OS vs Price, CPU vs RAM)
- Trained and evaluated a regression model
- Predicted laptop prices and compared to actual values

---

## 🪑 Project 2: E-Commerce Furniture Sales Analysis

**Objective:**  
Explore sales trends and product performance from an AliExpress furniture dataset with over 2,000 products.

### 🔧 Tools & Tech
- Python, Pandas, Scikit-learn
- Seaborn, Matplotlib
- TF-IDF Vectorization, Feature Engineering
- Linear Regression & Random Forest Regressor

### 📊 Key Steps
- Cleaned price and tag data (e.g., shipping info)
- Created new features like discount percentage
- Converted product titles to TF-IDF vectors
- Performed EDA on price vs sales
- Built models to predict number of items sold
